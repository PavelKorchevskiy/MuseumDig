# Museum Dig - Документация проекта

## 🎮 Общее описание

**Museum Dig** — idle-тайкун в изометрической перспективе, где игрок управляет музеем динозавров. Основная цель — раскапывать ископаемые, собирать коллекции скелетов, выставлять их в музее и привлекать посетителей для получения дохода.

**Ключевые особенности:**
- Изометрическая графика с динамическими посетителями
- Система коллекций скелетов с разной редкостью
- Дерево навыков с двумя ветками развития
- Экономика, основанная на посещаемости музея
- Система офлайн-наград
- Полная локализация (русский/английский)

---

## 🏛️ Система музея

### Архитектура музея
Музей состоит из нескольких комнат, расположенных на глобальной изометрической сетке. Каждая комната имеет глобальные координаты, список размещённой мебели, статус открытости и альфа-канал для визуализации.

**Скрипты:** `MuseumLayout.cs`, `Room.cs`

### Мебель в музее
Два типа мебели:
- **Витрины** — хранят находки (кости, минералы, артефакты)
- **Скелеты** — собранные коллекции динозавров, основной источник посетителей

Разная редкость скелетов влияет на количество привлекаемых посетителей.

**Скрипты:** `PlacedFurniture.cs`, `DisplayCase.cs`, `CollectionExhibit.cs`

### Посетители
Динамический спавн на основе количества скелетов в музее. Посетители блуждают по музею, осматривают экспонаты, останавливаются у витрин и скелетов, затем покидают музей. Приносят монеты при появлении.

Используют систему коллизий для обхода мебели и корректную сортировку глубины (Z-индекс) для правильного отображения.

**Скрипты:** `VisitorManager.cs`, `Visitor.cs`

## 🎒 Система инвентаря

Инвентарь хранит предметы в словаре, где ключ — ID ресурса. Имеет 5 вкладок:
- **Skeletons** — собранные скелеты
- **Assembling** — доступные для сборки коллекции
- **Findings** — обычные находки
- **Bones** — части коллекций
- **Tickets** — билеты на раскопки

Поддерживает диалог продажи с ползунком для выбора количества и сборку коллекций из частей.

**Скрипты:** `InventorySystem.cs`, `InventoryUI.cs`, `FoundItem.cs`, `SellItemDialog.cs`

## 🌳 Система навыков

Чистый C# синглтон, не наследуется от Node. Управляет деревом навыков с двумя параллельными ветками: Музей и Раскопки.

Каждый навык имеет: ID, название, описание, иконку, позицию в графе, пререквизиты, максимальный уровень, стоимость по уровням, тип эффекта, значения по уровням и флаг (числовой или флаг-навык).

**Реализованные навыки:**
- **Ветка Музея:** цена билета, макс. посетителей по редкостям, шанс билета, открытие новой комнаты, большая витрина
- **Ветка Раскопок:** количество и скорость землекопов/извлекателей, открытие экскаватора

Системы получают модификаторы через строковые ключи эффектов.

**Скрипты:** `SkillSystem.cs`, `SkillDefinition.cs`, `SkillData.cs`

### UI дерева навыков
Отображает обе ветки рядом с золотыми и серыми линиями связей. При клике на ячейку открывается панель деталей с описанием, текущим уровнем и кнопкой улучшения. Поддерживает сброс навыков за монеты.

**Скрипты:** `SkillTreeTab.cs`, `SkillNodeUI.cs`, `SkillDetailPanel.cs`

## 📊 Система прогресса

Чистый C# синглтон для отслеживания открытых предметов. Хранит HashSet'ы открытых коллекций и ресурсов. При первом получении предмета начисляются очки навыков в зависимости от редкости.

Предоставляет списки открытых предметов для UI вкладок прогресса.

**Скрипты:** `ProgressSystem.cs`

### UI вкладок прогресса
Три вкладки:
- **Дерево навыков** — визуализация графа
- **Открытые скелеты** — сетка карточек
- **Открытые находки** — таблица с иконками

**Скрипты:** `ProgressUI.cs`, `UnlockedSkeletonsTab.cs`, `UnlockedFindingsTab.cs`

## 💰 Экономика

**Источники дохода:**
- Посетители — основная валюта, приносят монеты при появлении
- Продажа предметов — через инвентарь, цена зависит от редкости

**Расходы:**
- Сброс навыков
- Покупка витрин (планируется)
- Билеты на раскопки (планируется)

**Скрипты:** `Wallet.cs`, `MuseumSystem.cs`

---

## 💾 Система сохранений

Сохраняет все данные игры в JSON формат. Поддерживает автосохранение с интервалом и принудительное сохранение при закрытии.

Включает: монеты, уровни инструментов, энергию, данные музея, инвентарь, открытые предметы, уровни навыков, свободные очки навыков, временную метку последней сессии.

**Скрипты:** `SaveSystem.cs`

### Офлайн-награды
Рассчитывает монеты за время отсутствия игрока на основе расчетного дохода музея. Имеет лимит в несколько часов.

**Скрипты:** `OfflineRewardSystem.cs`

## 🌍 Система локализации

Два CSV файла с форматом `keys,en,ru`. Godot сам выбирает нужную колонку по коду языка. Поддерживает подстановку параметров в строки.

**Скрипты:** `LocalizationManager.cs`

## 🎨 Визуальные системы

Изометрическая сетка с конвертацией координат. Спрайты посетителей с анимациями и направлениями. Все UI элементы создаются программно без .tscn файлов.

**Скрипты:** `IsoUtils.cs`, `MuseumConstants.cs`

## 🚧 Планируемые функции

### Система билетов на раскопки
Билеты — расходный материал для доступа к локациям раскопок. Можно купить за монеты или получить от посетителей. Некоторые локации требуют билеты только от посетителей.

### Система раскопок
Отдельная сцена с локациями раскопок. Землекопы и извлекатели для автоматической добычи. Экскаватор как продвинутый инструмент. Разные типы ресурсов на разных локациях.

### Дополнительные возможности
- Большая витрина (требует навык)
- Дополнительная комната музея (требует навык)
- Всплывающий текст "+X монет"
- Уведомления об открытии новых предметов
