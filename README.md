# Museum Dig - Документация проекта

## 🎮 Общее описание

**Museum Dig** — мобильный idle-тайкун в изометрической перспективе, где игрок управляет музеем динозавров. Основная цель — раскапывать ископаемые, собирать коллекции скелетов, выставлять их в музее и привлекать посетителей для получения дохода.

**Платформа:** Мобильные устройства (iOS/Android), портретная ориентация  
**Движок:** Godot 4.x с C#  
**Управление:** Сенсорное (тапы, свайпы, pinch-to-zoom)

**Ключевые особенности:**
- Изометрическая графика с динамическими посетителями
- Система коллекций скелетов с разной редкостью
- Система конкреций с разбивкой молотком
- Дерево навыков с двумя ветками развития
- Экономика, основанная на посещаемости музея
- Система офлайн-наград
- Полная локализация (русский/английский)
- Режим разработчика с отладочными функциями

**Скрипты:** `CameraController.cs`, `MuseumBottomBar.cs`, `MuseumTopBar.cs`

## 🏛️ Система музея

### Архитектура музея
Музей состоит из нескольких комнат, расположенных на глобальной изометрической сетке. Каждая комната имеет глобальные координаты, список размещённой мебели, статус открытости и альфа-канал для визуализации.

**Скрипты:** `MuseumLayout.cs`, `Room.cs`

### Фон и декорации
- **Дорожка** — параллельная дорожка от входа до развилки
- **Трава** — заполняет пространство вокруг музея
- **Деревья** — декоративные элементы на траве (настраиваемый массив)
- **Координаты сетки** — отображаются в режиме разработчика

**Скрипты:** `MuseumBackground.cs`

### Мебель в музее
Два типа мебели:
- **Витрины** (1×1 и 2×2) — хранят находки (кости, минералы, артефакты)
- **Скелеты** — собранные коллекции динозавров, основной источник посетителей

Разная редкость скелетов влияет на количество привлекаемых посетителей.

**Скрипты:** `PlacedFurniture.cs`, `DisplayCase.cs`, `CollectionExhibit.cs`

### Посетители
Динамический спавн на концах дорожки (левый/правый). Посетители блуждают по музею, осматривают экспонаты, останавливаются у витрин и скелетов, затем покидают музей через ту же точку входа. Приносят монеты при появлении.

Используют систему коллизий для обхода мебели и корректную сортировку глубины (Z-индекс) для правильного отображения.

**Скрипты:** `VisitorManager.cs`, `Visitor.cs`

## 🎒 Система инвентаря

### Структура
Модальное окно с непрозрачным фоном, заголовком, подсказкой и красной кнопкой закрытия внизу. Двухуровневая навигация через кнопки-вкладки.

### Вкладки (6 штук)
**Первый ряд (всегда виден):**
- **Билеты** — билеты на раскопки
- **Кости** — раскрывает второй ряд
- **Находки** — обычные находки
- **Конкреции** — конкреции для разбивки

**Второй ряд (появляется при нажатии на "Кости"):**
- **Сборка** — доступные для сборки коллекции
- **Скелеты** — собранные скелеты
- **Части костей** — части коллекций

### Функциональность
- Диалог продажи с ползунком для выбора количества
- Сборка коллекций из частей
- Размещение собранных коллекций в музее
- Разбивка конкреций молотком
- Использование билетов для перехода на раскопки

**Скрипты:** `InventorySystem.cs`, `InventoryUI.cs`, `FoundItem.cs`, `SellItemDialog.cs`

## 🪨 Система конкреций

Конкреции — специальные предметы, которые нужно разбить молотком для получения случайного содержимого.

### Механика
- Каждый тип конкреции требует определённое количество ударов (HitsToOpen)
- Анимация разрушения (5 кадров)
- Случайное содержимое из пула возможных предметов
- Кнопка "Следующая конкреция" при наличии нескольких штук

### UI разбивки
Отдельное модальное окно с:
- Изображением конкреции (центр экрана)
- Прогресс-баром ударов
- Кнопкой "Ударить молотком"
- Анимацией раскрытия и появления находки

**Скрипты:** `ConcretionDefinition.cs`, `ConcretionOpeningUI.cs`

## 🌳 Система навыков

Чистый C# синглтон, не наследуется от Node. Управляет деревом навыков с двумя параллельными ветками: Музей и Раскопки.

Каждый навык имеет: ID, название, описание, иконку, позицию в графе, пререквизиты, максимальный уровень, стоимость по уровням, тип эффекта, значения по уровням и флаг (числовой или флаг-навык).

**Реализованные навыки:**
- **Ветка Музея:** цена билета, макс. посетителей по редкостям, шанс билета, открытие новой комнаты, большая витрина
- **Ветка Раскопок:** количество и скорость землекопов/извлекателей, открытие экскаватора

Системы получают модификаторы через строковые ключи эффектов.

**Скрипты:** `SkillSystem.cs`, `SkillDefinition.cs`, `SkillData.cs`

### UI дерева навыков
Отображает обе ветки рядом с золотыми и серыми линиями связей. При клике на ячейку открывается панель деталей с описанием, текущим уровнем и кнопкой улучшения. Поддерживает сброс навыков за монеты.

**Скрипты:** `SkillTreeTab.cs`, `SkillNodeUI.cs`, `SkillDetailPanel.cs`

## 📊 Система прогресса

Чистый C# синглтон для отслеживания открытых предметов. Хранит HashSet'ы открытых коллекций и ресурсов. При первом получении предмета начисляются очки навыков в зависимости от редкости.

Предоставляет списки открытых предметов для UI вкладок прогресса.

**Скрипты:** `ProgressSystem.cs`

### UI вкладок прогресса
Три вкладки:
- **Дерево навыков** — визуализация графа
- **Открытые скелеты** — сетка карточек
- **Открытые находки** — таблица с иконками

**Скрипты:** `ProgressUI.cs`, `UnlockedSkeletonsTab.cs`, `UnlockedFindingsTab.cs`

## 💰 Экономика

**Источники дохода:**
- Посетители — основная валюта, приносят монеты при появлении
- Продажа предметов — через инвентарь, цена зависит от редкости

**Расходы:**
- Сброс навыков
- Покупка витрин (малая: 200 монет, большая: 400 монет)
- Билеты на раскопки (получаются от посетителей или покупаются)

**Скрипты:** `Wallet.cs`, `MuseumSystem.cs`, `MuseumShopUI.cs`

## 💾 Система сохранений

Сохраняет все данные игры в JSON формат. Поддерживает автосохранение с интервалом и принудительное сохранение при закрытии.

Включает: монеты, уровни инструментов, энергию, данные музея, инвентарь, открытые предметы, уровни навыков, свободные очки навыков, временную метку последней сессии.

**Скрипты:** `SaveSystem.cs`

## 🌍 Система локализации

Два CSV файла с форматом `keys,en,ru`. Godot сам выбирает нужную колонку по коду языка. Поддерживает подстановку параметров в строки через `string.Format`.

**Скрипты:** `LocalizationManager.cs`

## 🎨 Визуальные системы

Изометрическая сетка с конвертацией координат. Спрайты посетителей с анимациями и направлениями. Все UI элементы создаются программно без .tscn файлов.

**Скрипты:** `IsoUtils.cs`, `MuseumConstants.cs`

## 🔧 Режим разработчика

Конфигурируемая система отладочных функций через файл `dev_mode.cfg`.

**Доступные функции:**
- **FreeCamera** — свободное перемещение камеры без ограничений
- **ShowGridCoords** — отображение координат сетки над тайлами
- **HighDropChance** — повышенный шанс дропа
- **InfiniteGold** — бесконечные монеты
- **SpawnVisitorsFast** — ускоренный спавн посетителей

**Скрипты:** `DevMode.cs`
